# 2026-09-14

## 知识库 Web UI 持续打磨

### Tree Pane 工具栏改为两排 + 勾选模式批量操作
- 第一排:状态过滤 + 全部展开/收起
- 第二排:批量加入/批量移除(进入勾选模式才出现取消+确认按钮)
- 勾选模式:add 模式只让 excluded 文件可勾,remove 模式只让 indexed/pending 可勾,disabled 状态视觉变灰
- FileTree 维护 `selectMode: 'add' | 'remove' | null` + `picked: Set<string>`,Knowledge.tsx 不再自己管折叠态
- 文件行勾选用自定义 `.tree__check` 样式(避免原生的 checkbox 在各浏览器不一致)

### Tree Pane 折叠按钮从 pane 内移到 topbar
- Layout 管理 `treeVisible` + 持久化到 `akm.tree.visible`,通过 KnowledgeContext 暴露给 Knowledge
- 删除 `.tree-pane.is-collapsed` 动画宽度方案,改为条件渲染(简单且不会留残影)
- 删除 `.tree-pane__handle` 相关 CSS

### Resize Handle 加宽
- `.resize-handle` 4px → 6px,`::before` hit area 12px → 16px,实际可点击区更宽

### 新增图标
- PlusIcon / MinusIcon(批量按钮内联)
- 改造 ExpandIcon / CollapseIcon 为"侧栏 + chevron"形态,语义化为折叠/展开 panel

### 经验教训
- Playwright `page.route('http://127.0.0.1:5173/api/**')` 精确匹配,避免误伤 `/src/api/client.ts` 这种源码路径
- 截图脚本里用 `aria-label` 找按钮时,要确认 i18n key 的最终值(layout.collapseTree='收起文件树',不是 filetree.collapseAll='全部收起')
- React onMouseDown 在 outerHTML 看不到 listener,但 React 用合成事件正常生效
- CSS Grid 三列布局时,中间列要给具体宽度,不能 auto(否则会吞掉第三列空间)
