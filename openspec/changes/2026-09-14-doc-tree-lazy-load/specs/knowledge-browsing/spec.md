# knowledge-browsing 能力增量(文档树懒加载)

## MODIFIED Requirements

### Requirement: Collapsible Tree Navigation
文档树 SHALL 默认收起,目录可逐级展开/收起,展开状态按节点持久化;**目录内容 SHALL 按需加载:展开某目录时才请求该目录的一层直接子项,已加载目录在会话内缓存(切节点后失效重拉)。**

「全部展开」SHALL 保留,实现为一次全量请求后本地拆平缓存(用户显式触发)。

#### Scenario: 展开目录按需加载
- **WHEN** 用户展开一个尚未加载的目录
- **THEN** 前端仅请求该目录的一层子项(网络面板仅一条 `?dir=` 请求),加载期间显示行内 loading

#### Scenario: 并发展开防重
- **WHEN** 用户快速连点/反复展开同一目录
- **THEN** 该目录仅发出一次请求(在途复用)

#### Scenario: 点选文件不触发树请求
- **WHEN** 用户点选树中一个文件
- **THEN** 仅右栏渲染文档,不触发任何树数据请求

#### Scenario: 搜索跳转 / URL 深链逐层展开
- **WHEN** 从搜索结果跳转或直接访问深层文档 URL
- **THEN** 树自动把祖先目录逐层加载并展开,定位高亮该文件

#### Scenario: 切换节点恢复展开集
- **WHEN** 用户切走再切回某节点
- **THEN** 展开集从 localStorage 恢复,相关目录按需重新拉取;不同节点间数据不串

#### Scenario: RAG 状态过滤范围
- **WHEN** 用户按 RAG 状态过滤且未全部展开
- **THEN** 过滤作用于"已加载且已展开"的范围(全部展开后等价旧行为)

#### Scenario: RAG 操作局部刷新
- **WHEN** 管理员对文件加入/移出 RAG(单篇或批量)
- **THEN** 仅重载受影响文档所在目录的切片,叶子状态徽即时更新

#### Scenario: 空节点引导
- **WHEN** 所选节点根切片为空
- **THEN** 中栏显示"暂无文档"空态与「立即扫描」入口(与既有行为一致)
