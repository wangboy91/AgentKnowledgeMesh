# 验收计划（未执行产品验收）

本轮已获最小实施授权，以下场景只使用临时目录/隔离数据库；不得使用用户原文件做破坏性实验。安全修复已有 14/217 项结果仅来自实际读取的上一报告，不是本轮新测试。

| 编号 | 场景 | 必须观察到的结果 |
| --- | --- | --- |
| V1 | A 授权改 B 文件，B 授权改 A 另一文件 | 对应 owner 的实际磁盘字节改变；另一 Node 没有工作副本；Hub committed hash 一致 |
| V2 | 未授权、viewer、只读 token、匿名、撤销/禁用 | 无磁盘/Hub 版本变化；HTTP MCP 会话归属安全回归保持有效 |
| V3 | 同基础版本两次写，或本地编辑竞争 | 至多一次提交，其余冲突；不能静默覆盖 |
| V4 | ..、UNC、盘符、ADS、大小写别名、symlink/junction 与父目录替换 | 安全拒绝，根内外非目标文件不变 |
| V5 | 写盘失败/Hub 提交失败/ack 或响应丢失/重启 | 不提前报成功；unknown 可用原 ID 查询对账；无重复写/版本 |
| V6 | 同 ID 同摘要重试、同 ID 不同摘要 | 前者返回相同结果，后者拒绝；保留范围外旧 ID 不当新操作 |
| V7 | owner 离线或旧协议 | 新写拒绝且不排队；已有未知操作保留待对账 |
| V8 | 本地与远程连续修改 | revision 单调、hash 对实际字节、来源/主体/时间/operation_id 可查 |
| V9 | A 主动删除并收到 Hub tombstone 确认 | 下表每个新请求都取不到内容；缓存与异步索引不能旁路 |
| V10 | tombstone 后延迟上传/ack/索引回填；同路径重建 | 旧代次不复活；重建用新 ID/代次、重新授权 |
| V11 | 根不可达/不完整扫描/权限丢失 | 标不可达，不批量删除，不错误 tombstone |
| V12 | 离线物理删除 | 明示未同步边界；上线删除确认后满足 V9 |
| V13 | owner 离线正文读取/检索 | 明确不可用；Hub 仅查询元数据，跨节点搜索标明不完整 |
| V14 | 严格存储边界 | Hub 无新全文/chunk/历史正文/embedding；队列、日志、审计、异常、缓存、临时文件无正文 |
| V15 | 客户端与第三方 | AKM 客户端无正文草稿/会话/离线缓存；未验证第三方正文工具默认不开，外部/OS 边界明确 |
| V16 | 迁移盘点与清理 | 旧全文/索引/历史/备份逐项盘点；永久删除另获确认；旧副本存在时不宣称零副本 |

删除读取矩阵（V9 全部通过才算通过）：

| 入口 | tombstone 后新请求期望 |
| --- | --- |
| 文档列表、节点列表下文档、目录树 | 不列为可读文件、不携正文/片段 |
| 详情及按 ID/path 获取 | 404/410 或明确已删除，无正文 |
| 关键词、向量、混合检索与 Context API | 无命中内容/摘要/片段；旧索引不泄漏 |
| REST/API 与全部 MCP 接入形态 | 同一屏障，无旧缓存正文 |
| 历史正文/版本详情/操作查询 | 无历史或请求正文；必要受控元信息可保留 |
| 分页、缓存、索引重建及后台结果返回 | 返回前检查 active/代次；不复活 |

删除承诺从 Hub 确认 tombstone 起算；不宣称清除外部已下载内容，也不把可见性删除等同永久物理清除所有历史。存储选择已确认；实施授权不等于验收通过。



## 当前只读 profile 实测（不等于完整写回验收）

- 23 项新增 Hub/共享读取测试 + 原 HTTP MCP 14 项：37 passed。两套逻辑 owner 的注册/元数据回报经过真实 owner_websocket 消息处理，磁盘读用真实 OwnerReader，客户端为进程内 HTTPX。WS 传输使用进程内队列，未启动端口；不是两台真实电脑验收。
- Node 严格编排 3 项：显式根、主体隔离状态、元数据扫描/内存回复、拒绝 write action、严格分支不调用旧同步。
- 已测读取/搜索、无授权/匿名拒绝、授权到期/撤销、读取途中撤权和源删除、离线/超时、owner 禁用/令牌轮换、伪造 manifest/跨 owner 回包拒绝、墓碑/重建、不完整/不可达/重解析根不删除、旧全文 REST/MCP 停供、旧数据库正文仍保留、状态库不含合成正文标记。
- Windows secure_read 真实读句柄已执行；重解析根防删除使用确定性的属性注入，不声称真实恶意 junction 替换、OS swap 或第三方客户端均已验证。
- 当前 profile 写回返回明确不支持，V1/V3/V5/V6 等写回场景仍未通过；未做 PostgreSQL、真实 Mac/Windows、多 worker、Web 新页面、旧副本物理清理或第三方不落盘验收。
