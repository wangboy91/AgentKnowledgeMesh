# knowledge-browsing Specification

## Purpose
知识库页提供"节点 → 目录树 → 文档渲染"的三栏浏览体验,支持按节点导航目录、默认收起可展开、点选即渲染。

## Requirements

### Requirement: Three-Pane Knowledge Layout
知识库页 SHALL 呈现三栏布局:左栏为节点选择列表,中栏为所选节点的文档树,右栏为选中文档的 Markdown 渲染;未选中文档时右栏 SHALL 显示占位引导;视口宽度小于 1024px 时 SHALL 退化为两栏(树与渲染切换)。

#### Scenario: 选择节点加载树
- **WHEN** 用户在左栏选择某节点
- **THEN** 中栏加载并展示该节点的文档树(仅含该节点文档)

#### Scenario: 点选文档渲染
- **WHEN** 用户在中栏点选一个文档
- **THEN** 右栏渲染该文档的 Markdown 内容(GitHub 风格)

### Requirement: Collapsible Tree Navigation
文档树 SHALL 默认收起,目录可逐级展开/收起,展开状态按节点持久化;**目录内容 SHALL 按需加载:展开某目录时才请求该目录的一层直接子项,已加载目录在会话内缓存(切节点后失效重拉)。**

「全部展开」SHALL 保留,实现为一次全量请求后本地拆平缓存(用户显式触发)。

#### Scenario: 默认收起
- **WHEN** 用户切换到一个节点(该节点无已记忆的展开状态)
- **THEN** 树仅显示根层级(一次 `?dir=` 请求),目录内容收起,不预加载更深层级

#### Scenario: 展开状态记忆
- **WHEN** 用户展开某目录后离开该节点,稍后重新选择该节点
- **THEN** 之前展开的目录保持展开,其切片按需重新拉取

#### Scenario: 批量展开收起
- **WHEN** 用户点击「全部展开」或「全部收起」
- **THEN** 「全部展开」为一次全量请求后本地拆平缓存并展开所有层级,「全部收起」回到仅根层级;两者均更新该节点的记忆状态

#### Scenario: 展开目录按需加载
- **WHEN** 用户展开一个尚未加载的目录
- **THEN** 前端仅请求该目录的一层子项(网络面板仅一条 `?dir=` 请求),加载期间显示行内 loading

#### Scenario: 并发展开防重
- **WHEN** 用户快速连点/反复展开同一目录
- **THEN** 该目录仅发出一次请求(在途复用)

#### Scenario: 点选文件不触发树请求
- **WHEN** 用户点选树中一个文件
- **THEN** 仅右栏渲染文档,不触发任何树数据请求

#### Scenario: 搜索跳转 / URL 深链逐层展开
- **WHEN** 从搜索结果跳转或直接访问深层文档 URL
- **THEN** 树自动把祖先目录逐层加载并展开,定位高亮该文件

#### Scenario: 切换节点恢复展开集
- **WHEN** 用户切走再切回某节点
- **THEN** 展开集从 localStorage 恢复,相关目录按需重新拉取;不同节点间数据不串

#### Scenario: RAG 状态过滤范围
- **WHEN** 用户按 RAG 状态过滤且未全部展开
- **THEN** 过滤作用于"已加载且已展开"的范围(全部展开后等价旧行为)

#### Scenario: RAG 操作局部刷新
- **WHEN** 管理员对文件加入/移出 RAG(单篇或批量)
- **THEN** 仅重载受影响文档所在目录的切片,叶子状态徽即时更新

#### Scenario: 空节点引导
- **WHEN** 所选节点根切片为空
- **THEN** 中栏显示"暂无文档"空态与「立即扫描」入口(与既有行为一致)

### Requirement: Search-to-Tree Linkage
顶栏全局搜索命中并选择某文档时,SHALL 跳转至知识库页、定位该文档、展开其所在路径并渲染到右栏。

#### Scenario: 搜索命中联动
- **WHEN** 用户在顶栏搜索并点选某命中文档
- **THEN** 界面切换到知识库页,该文档所在目录路径自动展开,右栏渲染该文档
